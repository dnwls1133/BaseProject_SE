# 두 세력 전장 작업 현황 — 2026-10-21

최신 사용자 요청에 따라 추가 확장은 중단하고 현재 변경의 코드·데이터 연결을 정리했다.
빌드, 실행, 테스트, 화면·성능 확인은 수행하지 않았다. 실행 성공을 확인한 버전이 아니다.

## 현재 반영한 범위
- 첫 맵 크기는 256×200 유지. 정화 기사단 24명, 군체 16개체로 외부 데이터를 재구성했다.
- 기사단의 네 마을(피난 마을·보급 교역촌·정화 요새·정화 수도원)은 기존 경제 시스템과 거래 경로를 사용한다.
- 군체의 일반 생활·거래 참여를 제한하고, 실제 오염 격자 확산과 소각·재확산 지연을 연결했다.
- SocietyConflict.cpp는 정의 로딩과 오염, SocietyConflictCombat.cpp는 전장 이동·공격,
  SocietyConflictSave.cpp는 전장 저장을 담당한다. 모두 Visual Studio 프로젝트에 등록했다.
- Data/Simulation/level1.conflict의 rules/attack/unit/seed 레코드로 수치를 관리한다.
- 횡베기·찌르기·화염·도약·포자·강타·감염 포낭의 예고/판정을 연결했다.
- 기존 3D 모델과 관절을 재사용한다. 새 외부 리깅 에셋을 추가한 것은 아니다.
- 군체는 일반 플레이어 공격 대상이다. 기사단 주민 공격에는 기존 X 조합을 유지한다.
- 기존 세력 분열·휴전 진행이 이 맵을 바꾸지 않도록 전장 모드에서 제한했다.
- 기존 5세력 서사 데이터는 삭제하지 않고 이번 맵의 로딩 참조만 해제했다.
- 저장 스키마는 8이다. 이전 스키마/콘텐츠 서명의 저장은 호환되지 않으며 기존 파일을 삭제하지 않았다.

## 아직 확인하거나 확장하지 않은 부분
- 컴파일·링크 및 실제 콘텐츠 로딩 성공, 화면 표현, 공격·이동·경제 균형은 사용자 확인 전이다.
- 기존 모니터의 NPC 피해 기록과 프로파일 계측은 재사용하지만 오염 전용 HTML 화면은 추가하지 않았다.
- 군체가 NPC 경로를 사용하므로 기존 몬스터 수 통계 및 몬스터 처치 보상 경로와 구분된다.
  새로운 군체 전용 보상·증원·장기 전쟁 균형 확장은 수행하지 않았다.
- 기존 Scene 업데이트와 화면 밖 저빈도 NPC 처리, 지형 Actor 렌더 경로를 사용한다.
- 전장은 로컬 규칙 기반 초기 구현이며 학습 AI나 완성된 전략 시뮬레이션으로 설명하지 않는다.
