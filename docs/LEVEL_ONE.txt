# 첫 레벨 구현 안내 — 성혈의 황야

최신: 2026-09-22. 사용자의 요청에 따라 첫 전투 레벨을 열린 야외 공간으로 전환하고, 콘텐츠를 외부 파일에서 로딩하도록 변경했다. 이번 변경의 빌드·실행·테스트·화면 확인은 수행하지 않았다. 이전 맵·환경·몬스터 개선판의 품질은 사용자가 직접 확인했으며 이후 기본 품질로 유지한다.

## 공간 구성

- 기본 맵은 `Data/Levels/level1.world`에 정의한 80×64다. 24~160타일/축 범위에서 파일로 크기를 변경할 수 있다.
- 넓게 이어진 황무지를 기본으로 하며 길 밖으로도 이동한다. 방을 둘러싼 벽과 그 방을 잇는 좁은 통로 생성 방식은 제거했다.
- 성소, 순례길, 묘역, 습지, 대성당 잔해, 균사 자생지 등 9개 구역을 길과 넓은 들판 위에 배치한다. 구조물은 부분적인 폐허와 랜드마크다.
- 고정 지형·길·랜드마크는 파일 배치를 유지한다. 적 위치, 주변 잔해·군락의 흩뿌리기, 미세한 색 변화는 재생성 시드로 달라진다.
- 얕은 물은 통과할 수 있다. 큰 소품은 정의에 따라 점유 타일에 충돌을 만들며 낮은 잔해와 시체는 바닥에 그린다.
- 시작점에서 이동 가능한 영역을 조사하고 고립된 바닥은 제거한다. 제단의 접근성을 확인하고 적은 도달 가능한 바닥에 배치한다.
- 미니맵은 가변 맵 크기에 맞춰 축소하고 길·물·석재를 구분한다. 가까운 제단을 청록색으로 표시한다.
- 유한 크기의 야외 첫 레벨이다. 본편 전체 스트리밍, 여러 레벨 사이 포털, 재실행 간 플레이 세이브는 아직 구현하지 않았다.

## 외부 데이터와 공통 코드

정확한 파일 위치·문법·새 레벨 제작 순서는 [외부 콘텐츠 제작 안내](CONTENT_PIPELINE.md)를 따른다. 다음 레벨은 새 `.world` 파일과 기존 카탈로그로 구성하며 `LevelTwo.cpp` 같은 복제 클래스를 만들지 않는다.

| 파일 | 내용 |
|---|---|
| Data/world.catalog | 시작 레벨 파일 선택 |
| Data/Levels/level1.world | 크기·시작·지형·길·구역·색·적 구성·배치·목표 |
| Data/enemies.actors | 적 이름·모델·전투 수치·움직임 |
| Data/props.actors | 소품 모델·역할·충돌·렌더링 속성 |
| Data/rpg.rules | 플레이어 전투·성장·회복·교환 수치 |
| Data/models.catalog, Data/Models/*.model | 모델 21종의 도형·색·재질·관절 |

- `ContentData`: 공통 UTF-8 레코드 읽기와 구문 오류 위치 보고.
- `LevelData`: 레벨/적/소품/성장 데이터 읽기, 범위·중복·ID 참조 검사.
- `RandomLevelMap`: 외부 정의로 열린 지형·도로·충돌·장식 배치 구성, 접근성 처리.
- `LevelOne`: 파일 경로를 받아 기존 전투·성장·Actor·Scene Graph 흐름을 재사용한다. 새 데이터 구성을 성공적으로 읽은 후 Scene을 교체한다.
- `ModelCache`: 외부 도형 파일의 공통 삼각형 생성과 캐싱, 관절 애니메이션. 캐시 형식은 4, 모델 내용 해시가 바뀌면 자동 갱신한다.
- `Game`: 데이터 로딩 성공 시에만 첫 레벨로 진입한다. 실패하면 튜토리얼에 오류를 표시하고 콘솔에 원인을 남긴다.

## 전투와 성장

튜토리얼 시작 직후 대화/부탁 진행 전에는 1, 튜토리얼 완료 후에는 E로 입장한다.

| 조작 | 동작 |
|---|---|
| WASD | 화면 방향 이동 |
| Space | 마지막 이동 방향으로 반복 근접 공격 |
| E | 전리품 획득, 근처 제단 회복·파편 교환 |
| Q | 회복약 사용 |
| Tab / 1·2·3 | 능력치 창 / 힘·생명·저항 배분 |
| Esc | 창 닫기 또는 일시정지 |
| R | 제단 근처·적 전멸·사망 시 현재 데이터 재로딩 및 사냥터 재생성 |

현재 파일의 목표는 캐릭터 레벨 3, 아이템 1개 획득, 능력치 1포인트 배분이다. 목표는 .world에서 변경한다.

가시 순례자(체력 48/경험치 28), 우화한 종지기(88/45), 기어오는 성혈(36/24)을 구역별 최대 25마리로 구성했다. 시작점과 적끼리 간격을 두고 공격 예고를 표시한다. 처치 시 경험치를 자동 지급하며 전리품은 E로 획득한다.

성장 초기값은 경험치 60+(레벨-1)×35, 레벨업 2포인트, 체력 100+(레벨-1)×5+생명×15, 공격 18+(레벨-1)×2+힘×4, 방어 2+저항×2다. 회복약은 40 회복, 제단은 파편 3개를 회복약 1개로 교환한다. 이 수치의 실제 원본은 rpg.rules이며 UI도 같은 데이터를 참조한다.

같은 실행 안에서 사망·재생성 후 경험치·능력치·소지품은 유지한다. 재실행 간 저장은 모델 캐시에만 해당한다.

## 시각 품질

기존 플레이어의 후드·겹망토·갑옷·성혈 병·검, 변이체 3종의 실루엣과 부위 표현, 아치·벽체·묘비·성상·운구 수레·균사 군락을 외부 모델 파일로 옮겼다. 기존 모델을 단순화하거나 새로 대체하지 않았다.

보행·호흡·망토·공격·피격·쓰러짐, 접지 그림자·화로 빛 번짐·낮은 안개·포자, MSAA·FXAA·블룸·한국어 UI를 유지한다. 바닥은 외부 팔레트와 타일 종류에 따라 초지·흙길·물·석재를 구분한다. 지형/분위기 묶음과 배치 객체는 Actor 및 Scene Graph를 통한다.

새 지형 표현과 로딩 구조는 아직 실행 확인 전이다. 사용자는 길 밖 이동과 소품 충돌, 구역별 분위기, 적 추적·성장, 오류 표시, R로 데이터 재로딩, 재실행 모델 캐시 상태를 직접 확인한다.

## 야외 나무 추가 — 2026-09-22

- `Data/Models/DeadTree.model`: 비대칭 마른 가지, 갈라진 수피, 부러진 가지의 밝은 단면, 옹이 구멍과 드러난 뿌리를 가진 고목.
- `Data/Models/BlightedTree.model`: 휘어진 줄기, 속이 빈 감염 조직, 붉은 층상 버섯, 창백한 균사와 작은 감염낭을 가진 감염목. 기존 fungal 역할로 지면의 붉은 빛을 연결한다.
- `models.catalog`에 두 모델을 추가하고 `props.actors`의 `dead_tree`·`blighted_tree`로 재사용한다. 모델은 총 21종이며 기존 첫 19개 모델 순서는 유지한다.
- `Levels/level1.world`에는 시작 지점 주변·습지 가장자리·감염 지대의 고정 나무 6그루와 작은 무리 형태의 무작위 나무 최대 24그루를 배치했다. 무작위 배치는 최소 4타일 간격이며 도로·석재·물·시작점 주변을 피한다. 실제 수량은 배치 가능한 공간에 따라 줄어든다.
- 나무는 기존 Prop Actor와 Scene Graph, 접지 그림자, 큰 장식의 플레이어 가림 처리를 사용한다. 줄기 점유 타일에 충돌이 있고 가지 전체가 충돌하는 것은 아니다. 나무 자체의 바람 흔들림은 추가하지 않았다.
- C++·셰이더·캐시 형식 변경 없이 외부 데이터만 추가했다. 배포 Data에 반영하고 프로그램을 재시작하면 원본 내용 해시로 모델 캐시를 자동 갱신한다. 위치·수량은 .world, 형상·색은 해당 .model에서 수정한다.
- 빌드·실행·테스트·화면 확인은 수행하지 않았다. 사용자는 나무의 크기·가지 가림·구역별 밀도와 길 밖 이동 시 줄기 충돌을 확인한다.

## 세계 시간과 지역 상태 — 2026-09-28
첫 레벨에 세계 시간, 지역 식량/감염, 균사 식량 사건을 연결했다. 하단 HUD에 한국어로 표시한다.
플레이 진행 1초당 월드 2분이며 Tab/ESC/사망 중 정지한다. 같은 월드 R 재생성에서는 상태를 유지한다.
지역 지표는 전투/소지품에 영향을 주지 않는다. 전체 범위와 데이터 조정·확인 항목은 docs/WORLD_SIMULATION.md를 따른다.
빌드·실행·테스트는 하지 않았다.
