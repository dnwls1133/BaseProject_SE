# 첫 레벨 구현 안내 — 성혈의 사냥터

2026-09-22 플레이어 개선: 사용자가 아래 맵·환경·몬스터 개선판의 실행 화면에 만족을 확인했다. 이를 향후 기본 품질로 유지하는 규칙을 AGENTS.md와 AGENTS.txt에 추가했다. 이번에 추가한 플레이어 모델·애니메이션은 아직 실행 확인하지 않았다.

2026-09-22 시각·배치 확장: 48×48 맵, 6개 테마의 9개 구역, 변이체 3종, 19종 모델 캐시(현재 버전 3), 바닥 디테일·안개·접지 그림자·화로 빛 번짐을 추가했다. 아래 내용은 변경 후 기준이며 빌드·실행·테스트·화면 확인은 수행하지 않았다.

2026-09-22: Actor의 업데이트·렌더링을 지속적인 Scene Graph 순회로 통합하고 구역 컬링·클리핑·패스 선택을 추가했다. [Scene Graph 안내](SCENE_GRAPH.md)를 따른다. 실행 검증과 성능 측정은 미수행이다.

2026-09-21 구조 변경: 플레이어·적·아이템·장식·피해 숫자와 지형·HUD 묶음을 Actor 기반으로 변경했다. 렌더링 순서와 정렬은 Scene이 담당한다. 상세는 [Actor 기반 화면 구성](ACTOR_ARCHITECTURE.md)을 따른다. 이후 시각 개선에 따른 변경은 위 최신 기록과 아래 항목을 따른다.

최초 구현: 2026-09-14. 최신 수정: 2026-09-22. 아래는 코드에 반영한 기능이며, 빌드·실행·테스트와 화면 확인은 사용자 요청에 따라 수행하지 않았다. 실제 난이도와 조작감은 첫 플레이 후 조정한다.

## 목적과 범위

튜토리얼 다음에 전투 → 전리품 획득 → 경험치 축적 → 레벨업 → 능력치 배분을 반복하는 작은 사냥터를 둔다. 파괴된 마을의 두 생존자와 기존 이야기 진행은 유지한다. 첫 레벨의 적은 자아를 잃은 변이체이며, 감염된 모든 존재를 적으로 규정하는 세계관 변경은 아니다.

사용자 확정 요구는 RPG 기본 기능, 도형 기반 모델 캐싱, 불꽃·물결 셰이더, 이동 영역이 연결된 랜덤 맵, 경험치 중심 성장이다. 사냥터 이름, 적 수, 레벨 3 목표, 성장 수치, 사망 시 경험치 유지 등은 이번 구현의 조정 가능한 초기값이다. 본편의 전투 규칙과 2D/3D 에셋 방식을 확정하지 않는다.

## 입장과 조작

- 튜토리얼 시작 직후, 대화 중이 아니며 감염자의 부탁을 받기 전에는 **1**로 첫 레벨에 바로 입장한다.
- 튜토리얼을 정상 완료한 화면에서는 **E**로 첫 레벨에 입장한다. **R**은 기존 튜토리얼 재시작이다.
- 첫 레벨에 들어간 뒤에는 아래 조작을 사용한다.

| 입력 | 동작 |
|---|---|
| WASD | 화면 방향 이동, 대각 이동 속도 정규화 |
| Space | 마지막 이동 방향으로 근접 공격. 누르면 반복 공격 |
| E | 가까운 전리품 하나 획득. 전리품이 없으면 시작 제단에서 휴식·교환 |
| Q | 회복약 1개로 체력 최대 40 회복. 체력이 가득 차면 소비하지 않음 |
| Tab | 능력치 창 열기/닫기. 열린 동안 전투 정지 |
| 1 / 2 / 3 | 능력치 창에서 힘 / 생명 / 저항에 1포인트 배분 |
| Esc | 능력치 창 닫기 또는 일시정지/계속 |
| R | 시작 제단 근처 또는 적 전멸 후 새 사냥터 생성. 사망 시 재도전 |

첫 목표는 **캐릭터 레벨 3 달성 + 아이템 1개 이상 획득 + 능력치 1포인트 이상 배분**이다. 목표를 달성해도 사냥을 계속할 수 있다. 여기서 ‘첫 레벨’은 플레이 구간이고 ‘캐릭터 레벨’은 성장 수치다.

## 전투와 아이템

- 시작 성소를 제외한 8개 구역에 각각 최대 3마리, 대성당에는 최대 4마리로 총 최대 25마리를 분산 배치한다. 시작점에서 10타일 이상 떨어뜨리고 서로 3타일 이상 간격을 둔다. 큰 맵에 맞춘 초기 밀도이며 플레이 후 조정한다.
- 플레이어 공격은 전방 부채꼴 범위, 벽에 가려지는지 여부, 공격 준비 시간과 재사용 대기시간을 사용한다. 공격 한 번에 같은 적을 중복 타격하지 않는다.
- 적은 플레이어까지의 바닥 경로를 따라 추적한다. 몸의 폭을 고려해 모서리를 우회하며, 공격 전 붉은 범위를 보여준다. 공격 준비 중 표시된 지점에서 벗어나면 회피할 수 있다.
- 피격 시 체력 감소, 짧은 무적 시간과 밝아지는 반응, 피해 숫자를 표시한다. 적 체력 막대와 사망 표현을 추가했다.
- 가시 순례자 체력 48 / 경험치 28, 우화한 종지기 체력 88 / 경험치 45, 기어오는 성혈 체력 36 / 경험치 24. 적 처치 시 회복약 또는 성혈 파편이 떨어진다. 경험치는 처치 시 자동 지급하고 전리품은 E로 줍는다.
- 시작점에 회복약 하나를 배치한다. 시작 제단은 E로 체력을 회복하며, 파편이 3개 이상 있으면 회복약 1개로 교환한다.
- 재도전·맵 재생성은 체력을 채우고 회복약을 최소 3개 확보한다. 동일 실행 중 경험치·능력치·기존 소지품과 목표 진행은 유지한다.

## 성장 초기값

`SimpleGame/RpgStats.h`를 전투와 UI가 함께 참조한다.

| 항목 | 계산 |
|---|---|
| 다음 레벨 필요 경험치 | 60 + (현재 레벨 - 1) × 35 |
| 레벨업 보상 | 능력치 2포인트, 최대 체력 +5, 공격력 +2 |
| 최대 체력 | 100 + (레벨 - 1) × 5 + 생명 × 15 |
| 공격력 | 18 + (레벨 - 1) × 2 + 힘 × 4 |
| 방어력 | 2 + 저항 × 2 |
| 적에게 주는 피해 | 공격력 - 적 방어력. 일반 적 방어 1, 큰 적 방어 5. 최소 피해 1 |
| 받는 피해 | 적 공격력 - 방어력. 순례자 공격 13, 종지기 공격 22, 기어오는 성혈 공격 10. 최소 피해 1 |
| 이번 프로토타입 성장 상한 | 캐릭터 레벨 20 |

남는 경험치는 다음 레벨로 넘기고 여러 레벨업도 처리한다. 체력 최대치 상승분은 현재 체력에도 더한다. 포인트가 없으면 능력치를 배분할 수 없다.

## 랜덤 맵과 접근성

`RandomLevelMap::Generate`는 매 입장·재생성 때 새로운 시드로 48×48 맵을 만든다. 9개 구역의 중심 위치·크기와 폭 3타일 연결 통로를 바꾸고 교차로를 추가해 순환 동선을 만든다. 테마 배치는 시작 성소를 기준으로 유지하여 무작위 배치에서도 공간의 역할을 읽을 수 있게 한다.

- 꺼져가는 성소: 안전한 시작 안뜰, 제단, 닳은 행렬 문양.
- 부서진 순례길: 가로로 긴 공간, 무너진 아치·벽·운구 수레.
- 이름 없는 매장지: 묘비 배열, 성상, 철책과 시체.
- 성혈이 고인 수로: 연속된 얕은 웅덩이, 차가운 바닥과 균사.
- 무너진 대성당: 십자형 공간, 네 기둥 자리, 행렬 문양과 추가 적.
- 우화의 정원: 둥근 공간 경계, 붉은 군락과 감염된 물.

`District`가 중심·가로/세로 반경·테마를 제공하고 `RegionAt`을 배치·바닥·HUD가 공유한다. 대성당 기둥과 매장지 묘비의 기단 네 곳은 이동 불가 타일로 먼저 만든 뒤 연결성을 보정한다. 구역 테마 이름과 세부 구성은 시각 구현을 위한 초기안이다.

시작점 기준 너비 우선 탐색으로 모든 이동 가능 타일을 조사하고, 연결되지 않은 바닥이 있으면 통로를 만들어 연결한다. 적 배치는 이 도달 가능 목록을 사용한다. 물 타일은 걸어서 통과할 수 있는 얕은 물이며, 벽체·아치·성상·묘비·수레·철책·군락 등 큰 장식은 막힌 지형에 놓는다. 이동 가능한 바닥에는 낮은 잔해와 시체만 배치하며, 시작 제단은 기존처럼 통과 가능한 상호작용 지점이다. 화로는 구역 가장자리의 이동 불가 지형에 둔다.

접근성의 대상은 플레이용 바닥 전체다. 암벽과 맵 바깥까지 이동 가능하게 만드는 의미는 아니다. 화면 밖 지형과 큰 장식은 렌더링에서 제외하며, 미니맵으로 연결된 길과 적 위치를 보여준다. 본편 전체 월드 스트리밍을 구현한 것은 아니다.

## 모델 캐시와 셰이더

`ModelCache::Build`는 원·타원·사각형·삼각형으로 총 19개 모델을 만든다. 기존 주인공·변이체 2종·기둥·뿌리·화로·제단·회복약·파편에 기어오는 변이체, 파괴된 벽, 아치, 성상, 묘비, 운구 수레, 균사 군락, 잔해, 시체, 철책을 더했다. `BuildCreatures`는 세 적의 체형·갈비뼈·갑각·감염 조직·천과 공격 부위를 구성하고, `BuildEnvironment`는 폐허의 옆면·상단 명암과 세부 장식을 구성한다. 위치·색상·재질·관절 태그를 가진 삼각형 정점 데이터로 저장한다.

처음 첫 레벨에 진입하면 모델을 만들고, 현재 사용 중인 Data 폴더의 **Cache/level1_models.bin**에 기록한다. 정상적인 x64 Debug 배포 실행에서는 `x64/Debug/Data/Cache/level1_models.bin`이다. 프로젝트 Data를 사용한 실행에서는 해당 Data 아래에 저장한다.

다음 프로그램 실행에서 첫 레벨에 진입할 때 유효한 캐시가 있으면 모델 생성 함수를 건너뛰고 읽는다. 파일의 매직 값·버전·모델 수·정점 크기·개수·체크섬·유효 범위를 검사하고, 손상되었거나 버전이 다르면 다시 생성한다. 임시 파일에 기록한 뒤 교체하며, 기록에 실패해도 현재 실행은 메모리 모델로 진행한다. **Esc 일시정지 화면**에 생성/저장/불러오기 상태를 표시한다.

모델 형상을 바꿀 때는 `ModelCache.cpp`의 `CacheVersion`도 올린다. 런타임 캐시는 Git에서 제외한다. 저장된 정점의 이동·관절 애니메이션과 화면 제출은 매 프레임 수행한다. 캐시 범위는 첫 레벨의 재사용 모델이며, 기존 튜토리얼 모델과 그림자·공격 표시 같은 동적 효과 전체를 디스크 캐시로 바꾼 것은 아니다.

`RendererShaders.h`의 지오메트리 프래그먼트 셰이더에 불꽃과 물 재질을 추가했다. 불꽃은 로컬 UV·시간·노이즈로 형태와 밝기를 바꾸고, 물결은 월드 위치와 시간으로 파문·반사 무늬를 계산한다. CPU가 매 프레임 불꽃 모양을 조립하지 않는다. 기존 MSAA·FXAA·블룸·색보정 경로를 사용하며 UI는 후처리 뒤에 그린다.

## 시각·애니메이션 개선의 구현 범위

- `ModelCache::Draw`: 관절별 회전, 실제 이동량에 따른 보행, 미세한 호흡, 공격 준비·타격·회복, 피격 반응, 쓰러짐을 처리한다. 관절의 삼각함수는 모델당 한 번씩 계산해 정점에서 재사용한다. 크기·좌우 반전으로 장식 반복감을 줄인다.
- 적 실루엣: 가시 순례자는 길고 마른 체형과 비대칭 팔, 종지기는 넓은 몸통·돌 갑각·큰 타격 팔, 기어오는 성혈은 낮은 몸통과 여섯 다리다. 공격 준비 시간은 각각 0.70 / 0.95 / 0.55초, 이동 속도는 1.65 / 1.15 / 2.1타일/초다.
- 적 사망 후 약 0.29초 동안 쓰러지며, 완료하면 바닥 패스로 옮기고 업데이트를 중단한다. 시체는 다른 Actor의 발밑에 남는다. 사망 모델을 제거하는 동작과 구분한다.
- `LevelOne::DrawGround`: 테마별 석재 색, 행렬 문양, 균열, 얼룩, 물가 테두리, 이동 영역의 연석을 그린다. 색·균열 변형은 시드와 좌표에 고정되어 카메라 이동 시 바뀌지 않는다.
- `DrawProp`: 접지 그림자와 화로 바닥 빛 번짐을 사용한다. 큰 장식이 플레이어 앞에 겹치면 반투명으로 그린다. 월드 좌표 배치는 Actor, 환경과 인물의 앞뒤 정렬은 Scene Graph가 담당한다.
- `DrawAtmosphere`: Effects 패스의 CallbackActor를 통해 구역별 낮은 안개와 드문 재·포자 입자를 합성한다. UI에는 안개를 적용하지 않는다.
- 셰이더 재질 `Organic`(9), `Mist`(10), `SoftLight`(11)를 추가했다. 조직의 미세한 맥동, 시간 기반 노이즈 안개, 부드러운 방사형 감쇠를 계산한다. 첫 레벨의 접지 그림자·빛 번짐은 효과 사각형 2개 삼각형으로 제출한다. 실제 동적 그림자 맵이나 물리 기반 조명은 아니다.
- HUD 상단은 현재 구역명을 표시한다. 적 이름과 체력은 가까우면서 피해를 입었거나 공격을 준비할 때 표시한다. 미니맵은 맵 크기에서 셀 크기를 계산한다.
- 캐시 버전은 **3**이다(플레이어 개선으로 갱신). 이전 버전은 다음 첫 레벨 진입 시 자동으로 새 모델을 생성해 저장한다. 이후 실행은 유효한 캐시를 읽는다. 캐시 파일을 직접 삭제할 필요는 없다.
- 새 배치 객체도 Actor와 Scene Graph를 거친다. 장식은 정적 공간 구역에, 분위기는 별도 그룹에 연결한다. 정적 컨테이너는 Scene 연결 전에 구성하며, 새로운 렌더 경계는 모델·빛 범위를 포함한다.

## 플레이어 시각 개선

`ModelCache::BuildPilgrim`에 첫 레벨의 플레이어 생성을 분리했다. 기존 도형 기반 캐싱 방식을 유지하면서 후드와 안쪽 얼굴, 천 마스크, 찢어진 겹망토와 봉제선, 어깨 갑옷·흉갑·무릎 보호대·장화, 벨트·주머니, 금속 테두리의 성혈 병, 손잡이·가드·검날을 구성한다. 어두운 청록색 천, 차가운 금속, 절제된 황동색 장식으로 붉은 감염체와 구별한다.

`ModelCache::Draw`는 플레이어에만 맞춘 관절 중심, 게임 시간에 따른 호흡·옷단 흔들림, 보행 시 팔과 망토의 지연된 움직임, 검을 든 팔의 공격 회전을 사용한다. `LevelOne::DrawPlayer`가 기존 게임 시간을 전달하므로 일시정지와 능력치 창에서도 애니메이션 시간이 함께 멈춘다. 공격 범위·피해량·재사용 대기시간·이동 속도·충돌 크기는 변경하지 않았다.

새 모델은 기존 캐시를 자동으로 버전 3으로 갱신한다. 모델 수는 19종 그대로다. 이 변경의 대상은 첫 레벨 플레이어이며, 튜토리얼의 VillageArt 인물 모델은 별도 구현이다.

직접 확인할 항목: 정지 중 호흡과 옷단, WASD 보행과 좌우 반전, Space 공격 시 손·검 연결, 어두운 지형에서 얼굴·망토·장비 식별, 피격 반응, 일시정지, 재실행 후 캐시 불러오기. 이번 플레이어 변경의 빌드·실행·테스트는 수행하지 않았다.

## 변경 위치

- `Game.h/.cpp`: 튜토리얼에서 첫 레벨 진입, 입력·업데이트·렌더링 전달.
- `LevelOne.h/.cpp`: 전투, 적 추적, 전리품, 사냥터 재생성, 표시 순서, 한국어 HUD·능력치 창·미니맵.
- `RpgStats.h`: 경험치·레벨·능력치 계산과 회복약 사용.
- `RandomLevelMap.h/.cpp`: 방·통로 생성, 연결 보정, 충돌·가시성·경로 탐색.
- `ModelCache.h/.cpp`: 도형 모델 최초 생성, 캐시 파일 읽기/쓰기, 저장된 관절 데이터로 애니메이션.
- `Renderer.h/.cpp`, `RendererShaders.h`: 효과용 UV 제출, 시간 전달, 불꽃·물결 셰이더.
- `SimpleGame.vcxproj`와 `.filters`: 새 소스 등록. 파일 시스템 사용을 위해 C++17 적용.
- `.gitignore`: 실행 중 만들어지는 모델 캐시 제외.

## 사용자가 직접 확인할 순서

1. Visual Studio에서 직접 빌드한 뒤, 처음 화면의 1 또는 튜토리얼 완료 화면의 E로 입장한다.
2. WASD 이동과 벽 충돌, 첫 회복약 E 획득, Space 공격 방향과 적의 공격 예고를 확인한다.
3. 적 처치 시 경험치가 한 번 지급되는지, 전리품을 중복 획득할 수 없는지 확인한다.
4. 캐릭터 레벨을 올려 Tab → 1/2/3으로 배분하고, 표시된 공격력·최대 체력·방어력과 실제 전투 변화를 확인한다.
5. Q 회복, 제단 휴식/파편 교환, 사망 후 R 재도전, 제단에서 R 맵 재생성을 확인한다. 여러 새 맵에서 길이 끊긴 곳이나 끼임이 있는지 살펴본다.
6. 화로 불꽃과 물결이 움직이고, 카메라 이동에 따라 효과가 물체에서 미끄러지지 않는지 확인한다.
7. 세 적의 실루엣·보행·공격 예고·쓰러짐, 큰 장식 뒤 플레이어의 가시성, 구역별 바닥/장식 차이를 확인한다. 적 밀도·안개 농도·그림자 밝기는 실제 화면 피드백으로 조정한다.
8. 첫 진입 후 Esc에서 캐시 저장 상태를 확인하고 프로그램을 종료한다. 다시 실행해 첫 레벨에 들어간 후 ‘모델 캐시 불러옴’ 표시를 확인한다.

현재 **경험치·능력치·아이템의 프로그램 재실행 간 저장은 구현하지 않았다.** 디스크에 저장하는 것은 모델 캐시다. 사망·맵 재생성 시 진행 유지는 동일 실행에 한정한다. 장비 슬롯·스킬·음향·본편 퀘스트 분기는 이번 범위에 포함하지 않는다.

첫 플레이 이후에는 공격 거리·준비 시간·적 밀도·회복량을 먼저 조정한다. 그 결과로 성장 수치를 정리한 다음, 필요에 따라 적/아이템 정의 외부화와 플레이 세이브를 추가하는 순서를 권장한다.
