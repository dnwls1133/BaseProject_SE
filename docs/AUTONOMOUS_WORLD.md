# 자율 사회와 확장 월드 구현 — 2026-09-28

## 범위와 검증 상태

사용자가 요청한 자율 NPC·세력·사건/퀘스트·저장 흐름을 기존 첫 레벨에 연결한 로컬 규칙 기반 프로토타입이다. 맵은 80×64에서 160×128로 바꾸었다. 가로/세로 각각 2배, 총 20,480타일로 면적 4배다. 무한 월드나 5개 대륙 전체를 스트리밍하는 구현은 아니다.

빌드·실행·테스트·화면/성능 확인은 수행하지 않았다. 아래 설명은 작성한 코드와 데이터의 동작 의도다. 실행 성공, 60 FPS, 모든 사건의 실제 발생을 확인한 것으로 해석하지 않는다. 복잡한 경제/정치/전쟁의 최종 밸런스가 완성되었다는 뜻도 아니다.

## 첫 배치

초기 주민은 이름 있는 NPC 25명이며 기존 변이체 적과 별도다. 사망·이탈·분열로 실행 중 인원과 소속은 달라질 수 있다. 세력마다 지도자 1명과 경비·상인·치료사·학자/피난민을 조합했다. 각 거점에 3명, 국경 교역로에 대표자 2명을 배치하여 서로 접촉할 수 있게 한다. 가로막힌 원본 좌표는 가장 가까운 이동 가능 셀로 보정한다.

## 시뮬레이션

- WorldSimulation이 소수점 시간을 누적하고 지역 식량/감염을 계산한다. ChangeRegion은 사회 활동과 플레이어 행동의 지역 자원 변경을 적용하고 변경 전후·주체·원인을 기록한다.
- 주민은 용기·탐욕·연민·의심·독단·호기심·개인성, 직책, 체력/식량, 알려진 지역 정보, 개인/세력 관계로 행동을 평가한다. 휴식·이동·교역·지원·순찰·조사·습격·후퇴·교전·동행을 지원한다. 거의 같은 점수의 후보에는 저장되는 난수 상태로 작은 차이를 준다.
- 정보는 현재 지역의 직접 관찰 또는 다른 주민의 메시지로 얻는다. 지역 위치는 알려진 지리로 사용하되 미방문 지역의 자원 수치를 자동 공유하지 않는다. 지원/교역 제안은 기억·계획·응답을 바꾼다. 지도자에게 보내는 보고는 거리 기반 도착 시간이 있는 메시지다. 실제 전령 캐릭터를 따로 생성하는 구현은 아니다.
- 기억한 식량 정보가 관찰과 크게 다르면 정보 제공자에 대한 신뢰가 낮아진다. 플레이어의 거짓 소문도 기억/행동과 이후 신뢰에 영향을 준다.
- 세력은 보급, 후계 지도자 선택, 지지, 통제 지역을 갱신한다. 불만과 신뢰하는 동료가 있는 인물은 독립 공동체를 만들거나 다른 세력으로 이적한다. 근거리 대표자 접촉과 이념·성향에 따라 교섭/동맹이 진행되고, 친화적인 소규모 빈곤 집단은 통합될 수 있다. 모든 변화가 시간표대로 반드시 발생하도록 강제하지 않는다.
- NPC끼리 경로를 따라 접근하고 공격 예고 후 거리·시야를 확인해 타격한다. 위험과 성향에 따라 후퇴하거나 항복을 요청할 수 있다. 피해·사망·후계 공백·관계·시설 손상·퀘스트 실패에 결과가 반영된다. 주민을 공격한 플레이어에 대한 반격도 지원한다.
- 지역에는 주민 수·통제 세력·치안·성혈 공급·군집 활성·공포·불만과 병원/창고/성벽의 추상적인 상태가 있다. 사망/분쟁은 손상을, 조사/순찰은 일부 회복을 반영한다. 건물의 형상을 실제로 파괴/재건하는 기능과 구분한다.
- 자비·질서·자유·정화·연결·기만은 행동으로 변하며 신뢰·가입/협상 판단과 정보 수용에 연결된다. 단일 선악 점수가 아니다.
- 기존 야생 변이체의 AI는 기존 전투 시스템을 유지한다. 이번 자율 전투는 사회 NPC 상호 간과 주민에게 적대한 플레이어를 대상으로 한다.

## 동적 요청

식량 부족·주변 부상자·피난민의 위험·연구 수요·적대 세력 접촉·낮은 치안에서 식량 전달, 치료, 호위, 조사, 협상, 방어 요청을 생성한다. 초기 고정 성장 목표는 별도로 유지한다.

제안·수락·진행·보류·완료·실패·만료·대체됨 상태를 관리한다. NPC가 스스로 문제를 해결하면 요청이 대체될 수 있고, 관련 인물이 사망하면 실패한다. 보류 중에도 기한과 세계가 진행된다. 완료 보상은 현재 초기값으로 경험치 35와 파편 2개다. 고정된 장 순서나 하나의 엔딩 플래그는 추가하지 않았다.

## 저장

배포 Data의 상위 폴더에 `Saves/world.save`를 사용한다. 통상 실행 파일 옆 Saves이며 authored Data/Cache와 구분한다. K 수동 저장, 정상 플레이 시간 약 60초마다 자동 저장, 시작 시 저장이 있으면 자동 복원, L 수동 복원을 제공한다. 마지막 저장 이후의 진행은 종료 시 잃을 수 있으므로 종료 전 K를 사용한다.

포함: 세계 시각/소수점 누적, 지역 상태, 플레이어 좌표·성장·소지품·전투 타이머, 맵 시드, 변이체 생존/전투 상태, 미획득 전리품, NPC의 위치·체력·소속·기억·개인 관계·현재 행동·경로, 세력/외교/시설, 카르마, 대기 메시지와 요청, 제한된 최근 이력, 난수 상태와 사건 ID.

일시적인 피해 숫자, 현재 열어둔 메뉴, 입력 키 상태는 복원하지 않는다. 자동 저장 중 부하도 프로파일 대상이다.

임시 파일을 완전히 작성한 뒤 기존 저장을 .bak으로 복사하고 Windows 파일 교체로 반영한다. 읽을 때 체크섬·버전·정의 해시·수치·ID 참조·위치를 확인하고 후보를 구성한다. 잘못된 저장은 현재 세계를 유지하며 자동 저장을 중단한다. .bak은 수동 복구용이며 자동으로 불러오지 않는다. K는 사용자가 현재 세계로 새 저장을 명시적으로 만드는 조작이다.

세계/사회/시뮬레이션/성장/적/소품 정의가 바뀌면 저장 호환성이 거부될 수 있다. 그런 경우 현재 파일을 백업하고 새 게임 상태에서 K를 사용한다. 기존 저장을 코드가 임의 삭제하지 않는다. 같은 실행에서 사회/월드 정의가 달라진 R 재로딩은 재시작 필요 오류를 낸다. 일반 재생성은 NPC 생존과 사회 상태를 보존하고 바뀐 장애물에 맞춰 위치/경로만 보정한다.

## 성능과 로그

지형은 역쿼터뷰 투영으로 화면 주변 셀 범위를 정한 후 기존 컬링/머터리얼 처리를 사용한다. 맵 확대가 매 프레임 전체 지형 스캔 4배로 이어지지 않게 했다. 주민 후보는 공간 버킷으로 제한한다. NPC 판단은 기본 월드 6분, 세력은 60분, 요청 후보 생성은 30분 간격이다. 화면에서 먼 NPC 이동/전투는 0.25초 단위로 같은 규칙을 사용한다. 렌더 컬링 때문에 세계 상태가 삭제되지 않는다.

경로 생성은 Update당 최대 2명, 메시지 처리 예산은 틱당 기본 16개/큐 256개, 정의 NPC 최대 128명, 전체 세력 기본 32개(해산 기록 포함), 요청 최대 96개, 최근 사건 이력 96개로 제한한다. 실제 저장/게임플레이 시나리오에 맞춘 값 조정은 후속 프로파일링 대상이다.

JSONL 계측: cpu_society_load_ms, cpu_society_update_ms, cpu_npc_decision_ms, npc_decision_count, cpu_npc_messages_ms, npc_message_sent_count, npc_message_dropped_count, npc_message_queue_count, cpu_faction_decision_ms, faction_decision_count, cpu_dynamic_quests_ms, dynamic_quest_created_count, social_npc_count, world_quest_record_count, cpu_npc_path_ms, npc_path_build_count, cpu_npc_motion_ms, cpu_npc_combat_ms, npc_strike_count, cpu_world_save_ms, cpu_world_restore_ms.

npc_decision_scores는 장기목표, 인지한 위협, 체력/식량과 행동별 점수를 남긴다. society_change는 change_id/cause_id/world_minute/kind/actor/target/before/after/reason을 포함한다. world_resource_change는 지역 ID·주체·원인·시간·식량/감염 전후 값을 기록한다. 타이머는 포함 시간이므로 상위 update와 자식들을 중복 합산하지 않는다. 행동 재현에는 같은 정의·저장·입력뿐 아니라 같은 시간 진행 조건도 필요하다.

## 외부 데이터 형식

`Levels/level1.world`의 `society Simulation/level1.society`를 사용한다. version 1 UTF-8 줄 단위 형식이며 기존 ContentData를 재사용한다. 정의 순서는 rules/weights → faction → territory/npc → diplomacy/relationship이다.

```
rules 판단주기 세력주기 메시지예산 메시지유효분 요청유효분 최대세력 대화거리 일일식량소비 공격거리 예고초 재공격초 적대임계값
weights 휴식 이동 교역 지원 순찰 조사 습격 후퇴 교전 동행
faction ID "이름" "이념문장" 본거지지역ID 장비모델ID R G B 이념축(-1~1) 비축자원
territory 지역ID 소유세력ID 치안 성혈 군집 공포 불만
npc ID "이름" 직책 장기목표 세력ID 출신지역ID 몸체모델ID X Y 용기 탐욕 연민 의심 독단 호기심 개인성 식량 감염 공격 이동속도
diplomacy 세력A 세력B 관계(-100~100)
relationship NPC_A NPC_B 신뢰 호감 존중 공포 의존 이념친화(-100~100)
```

## 첫 맵 세력 전쟁·생태 확장 — 2026-09-30 최신

이번 소스와 외부 데이터에 아래 내용을 추가했다. 이전 절의 160×128/25명/야생 몹 AI 미구현 표기보다 이 절이 우선한다. 빌드·실행·테스트·시각 품질·성능은 확인하지 않았다.

### 맵과 세력 거점
- 맵 256×200 = 51,200타일. 직전 20,480타일 대비 면적 2.5배이며 가로 1.6배, 세로 1.5625배다. 기존 9개 지역·도로·랜드마크·NPC 좌표를 함께 조정했다.
- 초기 주민 40명, 5개 세력에 8명씩. 기존 대표 5명에 경비병 3명을 보강해 민간인과 원정대 역할을 구분했다. 기존 야생 변이체 개체 수는 유지한다.
- 교단: 성혈 예배당, 첨탑·붉은 유리·석조 기둥과 포장 광장.
- 자치연합: 목조 창고, 천막 차양·상자·수레와 고목으로 둘러싼 피난 거점.
- 포자 공동체: 균사 성소, 유기적인 버섯 지붕·뿌리·감염목과 습윤 지형.
- 연구회: 관측시설, 금속 돔·관측통·청록 수조와 침수된 기록도시.
- 정화 기사단: 방어 전초, 흉벽·쇠창살·깃발과 울타리·화로.
- 새 모델 5종은 기존 ModelCache/정적 배칭/Actor/Scene을 재사용한다. 건물별 3×3 타일 점유는 보수적인 충돌 영역이며 메시 형태와 일치하는 정밀 충돌이 아니다. 광장과 중앙 접근로는 비워 배치했다.

### 플레이어와 독립적인 행동
- 몹은 가시 범위에서 플레이어, 적대 주민, 경쟁 몹 중 가까운 위협을 선택하고 기존 대상 유지 편향을 적용한다. 공격 예고 중에는 대상을 바꾸지 않고 타격 순간 거리·시야·생존을 다시 확인한다. 대상이 없으면 원래 영역 주변을 배회한다.
- 가시 순례자/종지기와 기어오는 성혈은 서로 경쟁하는 군집이다. 같은 군집은 무조건 공격하지 않는다. 세력과 종별 친화도를 통해 포자 공동체와 기어오는 성혈, 교단과 일부 순례 변이체의 공존을 표현한다.
- 주민은 가까운 적대 몹을 인지하면 용기·체력에 따라 교전하거나 멀어지는 경로로 도주한다. 공존하는 변이체가 다쳤고 가까이 있으며 비전투 상태라면 연민 성향 주민은 식량 1을 소비해 체력을 최대 12 회복시킨다.
- 몹에게 당한 주민의 피해·사망은 기존 공통 Damage 경로를 통해 공포·시설·지역 자원·관련 요청 실패에 반영된다. 몹 간 충돌과 주민의 몹 처치도 세계 기록에 남는다. 자동 처치에 플레이어 경험치·카르마·전리품을 지급하지 않는다.
- 세력 전쟁은 현지 접촉, 충분히 악화된 관계, 지도자의 이념 또는 식량 부족, 경비 병력과 보급으로 결정된다. 경비대의 원정과 수비대 지원 → 지역 교전 → 거점 근처 3명 이상과 상대 수비대 부재에 따른 통제권 변경 → 점령/병력·보급 손실/협상에 따른 휴전으로 연결된다. 발생 시점과 승자는 고정하지 않는다.
- 현재 전쟁은 소규모 경비대의 지역 분쟁 프로토타입이다. 다자 연합 작전, 진형, 공성 장비, 신규 병력 생산, 복잡한 보급로 차단까지 구현한 것은 아니다. 한 세력은 동시에 한 캠페인에만 참여한다.
- 대화와 요청 수락은 자율 활동의 조건이 아니다. 화면 밖 주민은 기존 저빈도 이동·교전을 사용하고 몹은 Scene을 통해 계속 갱신한다. Tab/ESC·능력치 창·플레이어 사망 정지는 기존 정책을 유지한다.

### 데이터·저장·계측
- `enemies.actors`: 종 정의 뒤 `rival 종A 종B`. 중복/자기 참조/없는 종은 거부한다.
- `.society`: 세력 정의 뒤 `ecology 세력ID 종ID 친화도(-100~100)`. 미지정 관계는 -60, 독립 공동체는 부모 세력의 종 관계를 상속한다.
- `.society`: `war_rules 적대임계값 시작보급 틱당소비 휴전분`. 현재 -60 / 2 / 0.35 / 1440. 기존 factionPeriod마다 갱신하며 실제 조정은 플레이 후 진행한다.
- `props.actors`: 소품 정의 뒤 `footprint 소품ID 반경(1~3)`. 반경 1은 중심을 포함한 3×3 타일이다. 기존 소품은 기본 0으로 중앙 타일만 점유한다.
- `LevelOneEcology.cpp`, `SocietyWar.cpp`를 프로젝트에 등록했다. 기존 공통 로더와 데이터 배포를 사용하며 런타임 API/LLM 의존성은 없다.
- 저장 체크포인트 schema 2에 캠페인·휴전과 개체의 대상/인지 타이머/영역/경로점을 추가했다. 기존 콘텐츠와 저장이 다르면 복원을 거부하고 자동 저장을 중지한다. 사용자가 기존 저장을 보관한 뒤 새 진행을 K로 저장할 수 있다. 저장을 자동 삭제하지 않는다.
- 몹의 공간 후보 수, 인지 CPU, 우회 경로 예산 보류, 타격 수, 전쟁 CPU/활성 수와 선택 원인·세계 시각을 기록한다. 몹 우회 경로는 49×49 영역, 프레임당 최대 2건이다. 주민은 기존 별도 경로 예산을 사용한다. 범위 밖 목적지까지 몹이 무한 추격하지 않는다.
