# 튜토리얼 프로토타입 구현 안내 — 시각 개선판

## 현재 구현
- OpenGL 3.3 기반 2.5D 쿼터뷰. 기본 창 1280×800.
- 맵 52×40: 기존 28×22 대비 면적 약 3.4배. 남문·주거 폐허·광장·예배당·약제소·묘역·동쪽 출구.
- 생존 인물은 주인공과 감염자 한 명. 여러 형태의 시체 및 선택 조사 기록 세 곳.
- WASD 화면 방향 이동, 충돌·카메라 추적, E 상호작용, 1/2 선택, Esc 일시정지, 완료 후 R 재시작.
- 마지막 성혈 획득 → 감염자에게 전달 → 마지막 대화 선택 → 출구 완료. 먼저 성혈을 얻는 경우도 지원.

## 렌더링 변경
1. 장면을 부동소수점 색상 버퍼에 렌더링한다.
2. 최대 4× MSAA로 도형 가장자리를 처리하고, 일반 텍스처로 리졸브한다. 해당 부동소수점 버퍼에서 샘플 수가 지원되지 않으면 낮춰 다시 할당한다.
3. 1/4 해상도 버퍼에서 밝은 영역을 추출하고 가로·세로 블러로 블룸을 만든다.
4. FXAA, 절제된 블룸 합성, 차가운 그림자·따뜻한 하이라이트 색감, 노출 매핑, 비네트, 미세한 그레인을 적용한다.
5. 한국어 UI를 후처리 이후 별도로 그려 문자 선명도를 유지한다.

재질은 외부 PBR 텍스처 대신 셰이더가 생성하는 돌 줄눈·습기·흙·목재 결·천·포장도로 패턴을 사용한다. 카메라 이동에 패턴이 미끄러지지 않도록 월드 기준 위치를 사용한다.

그림자는 가까운 등불 또는 기본 광원 방향으로 바닥에 투영한 형태에 여러 단계의 가장자리와 접지 음영을 합성한다. 3D 그림자맵이나 정확한 광원 차폐를 구현한 것은 아니다.

## 세계관에 맞춘 형태와 동작
- 주인공: 후드·눈가 가림·망토·가죽 띠·버클·붕대·장화·성혈 용기·검의 형태를 분리.
- 걷기: 이동 거리에 따른 보행 주기, 다리와 팔 교차, 상체 반동, 망토 흔들림. 정지 시 호흡.
- 감염자: 앉은 자세, 호흡과 간헐적 기침, 손의 균사 움직임. 투여 직후 반응과 마지막 대화 이후 인체 동작 정지.
- 배경: 불규칙하게 부서진 석벽, 교단 문양, 기둥과 아치, 찢어진 깃발, 피가 고인 우물, 제단, 운구 수레, 묘비, 뿌리 군락.
- 잔해: 석재 조각, 부러진 목재, 뼈 섞인 잔해로 구분.
- 바닥: 젖은 포장도로와 흙의 구분, 웅덩이·균사·풀, 발자국과 작은 파문.
- 안개와 포자는 월드 공간에서 움직이며, 카메라 이동에 따라 깊이 차이가 드러난다.

캐릭터 애니메이션은 분리된 도형 부위를 움직이는 절차적 2D 애니메이션이다. 외부 스프라이트 시트나 실제 3D 모델을 추가한 것은 아니다.

## 한국어
Windows의 맑은 고딕 계열 글꼴을 GDI로 2배 크기에 래스터화한 후 축소하여 표시한다. 텍스트 텍스처는 캐시한다. UTF-8 코드 포인트를 보존한 줄바꿈을 지원한다. UI·대사·목표·조사·완료 화면·창 제목을 한국어로 변경했다.

대사는 Data/dialogue.ko.txt에 `대화ID|화자|내용` 형식으로 분리했다. 빌드 시 맵 데이터와 함께 출력 폴더로 복사한다. 소스 컴파일 옵션에 /utf-8을 추가했다.

## 코드 구성
- Renderer.h/.cpp: 장면 버퍼, MSAA, 후처리, 도형 배치, 한글 텍스처.
- RendererShaders.h: 재질·블러·FXAA·색보정 셰이더.
- Game.h/.cpp: 데이터 로딩, 입력·이동, 퀘스트, 한국어 UI.
- VillageArt.cpp: 캐릭터와 환경, 그림자·바닥·분위기 효과.
- Data/village.level: 맵 크기, 시작점, 길과 오브젝트 배치.
- Data/dialogue.ko.txt: 한국어 대사와 선택 조사 기록.

## 사용자 확인 순서
1. Visual Studio에서 Debug / x64로 직접 빌드한다.
2. 출력 폴더 Data에 village.level과 dialogue.ko.txt가 있는지 확인한다.
3. 한국어 표시와 줄바꿈, 이동 중 벽·캐릭터 가장자리, 광원 번짐을 살펴본다.
4. 이동·정지·성혈 전달 시 인물의 다른 움직임과 깃발·포자를 살펴본다.
5. 목표 방향을 따라 퀘스트를 완료하고, 완료 화면의 시간을 확인한다.
6. 성혈 선획득과 두 선택의 진행, 창 크기 변경, 재시작을 확인한다.

## 범위와 확인 상태
- 필수 퀘스트는 계속 5분 이내를 목표로 한다. 넓어진 선택 지역을 모두 탐색하거나 멈춘 시간까지 제한하지 않는다. 실제 소요 시간은 미측정이다.
- 디스크 저장, 전투, 추가 생존자, 음원, 본편 전체 스트리밍은 포함하지 않았다.
- GPU별 성능·컴파일 성공·화면 품질은 아직 실행으로 확인하지 않았다.
- 사용자 요청에 따라 Codex는 빌드·실행·테스트·스크린샷 확인을 수행하지 않았다.
