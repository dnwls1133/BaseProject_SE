# 스켈레탈 애니메이션과 조합 정보

모든 캐릭터/몬스터 조합 GLB에 아래 12클립이 포함된다. 30fps이며 프레임 양끝을 포함하므로 길이는 `(끝-시작)/30`초다.
라이브러리 `.blend`의 액션을 Action Editor에서 고른다. NLA의 보관 트랙은 중복 적용을 피하도록 음소거했다.
열 때 기본 활성 액션은 Idle이다. 긴 액션을 볼 때 타임라인 종료 프레임도 아래 표에 맞춘다.

| 클립 | 프레임 | 반복 | 용도 |
|---|---:|---|---|
| BindPose_A | 1–2 | 아니오 | 인간형 A포즈, 몬스터는 각 계열의 기준 자세 |
| Idle | 1–60 | 예 | 호흡과 미세 움직임, 전환 기준 |
| Walk | 1–32 | 예 | 제자리 보행 |
| Run | 1–24 | 예 | 제자리 달리기 |
| TurnLeft90 / TurnRight90 | 1–20 | 아니오 | 루트의 좌/우 90도 회전과 발 디딤 |
| Attack | 1–30 | 아니오 | 인간형 무기 휘두르기, 사족 물기, 거미 앞다리/독니, 거대 이족 내려치기 |
| Jump | 1–36 | 아니오 | 웅크림·공중·복귀 자세와 골반/몸통의 시각적 들림 |
| WalkToRun | 1–18 | 아니오 | 걷기에서 뛰기로 변화하는 한 주기 예시 |
| RunToWalk | 1–20 | 아니오 | 뛰기에서 걷기로 변화하는 한 주기 예시 |
| Hit | 1–18 | 아니오 | 피격 반응 |
| Death | 1–48 | 아니오 | 쓰러짐, 마지막 자세 유지 |

## 보간 기준

BindPose_A는 스킨 기준 자세이고 Idle은 살아 있는 정지 상태다. 회전 전후에는 Idle 또는 현재 보행 자세를 사용한다.
모든 본 회전 키는 쿼터니언이다. 프레임 사이에는 가장 짧은 경로의 정규화된 보간/SLERP를 사용한다.
서로 다른 본/메시 버텍스 위치를 직접 섞지 않고 같은 리그의 본별 이동·회전·스케일을 블렌딩한 뒤 한 번 스키닝한다.

Turn은 기준 방향에서 출발해 90도 돌아서 끝난다. 루트의 yaw를 엔티티 방향에 소비하는 방식과
엔티티 방향을 직접 돌리고 루트 yaw를 제거하는 방식 중 하나를 사용한다. 둘을 함께 적용하면 회전이 두 번 발생한다.
45도 회전이 필요하면 클립의 해당 yaw 구간까지만 사용하거나, yaw를 목표 각도로 재매핑하고 몸통 자세를 보간한다.
기본 포즈를 경유해 매번 A포즈가 잠깐 드러나도록 전환하지 않는다.

## 걷기 ↔ 뛰기

기계 판독 정보는 `animation_blending.json`에 있다. 아래 블렌딩 시간과 이벤트 프레임은 게임 연결용 제안값이며 전투 판정 구현이 아니다.

1. 각 루프를 정규화 위상 0~1로 관리한다. 걷기 1–32와 뛰기 1–24를 같은 원시 프레임 번호로 연결하지 않는다.
2. 같은 위상에서 두 루프를 샘플링하고 속도에 따른 가중치로 섞는다. 두 발의 순서가 유지되도록 위상을 이어간다.
3. 가속 시 약 0.18초, 감속 시 약 0.22초의 가중치 변화를 초기값으로 사용한다.
4. 전용 WalkToRun/RunToWalk는 위상 0에서 시작해 위상 0으로 돌아오는 전환 예시다. 임의의 위상에서는 동기화 블렌딩을 우선하거나 먼저 위상을 맞춘다.

휴먼/거대 이족은 반대쪽 발의 위상이 0.5 주기 차이 난다. 사족은 대각선 다리가 함께 움직이는 보행이고,
거미는 좌우와 다리 번호가 번갈아 움직이는 4개 지지 다리 패턴이다. 고정 전투 판정이나 AI에는 연결하지 않았다.
접지 구간을 나눠 다리 IK를 계산한 후 FK 회전 키로 구웠으므로 GLB 재생 시 Blender IK 제약이 필요 없다.
이 키는 평면 기준이다. 경사·계단·물체 위 발 접지와 실제 캐릭터 이동에 맞춘 속도 보정은 게임에서 처리한다.

## 공격·점프·중단

Attack은 예고 → 타격 자세 → 복귀 구간을 가진다. 제안 타격 구간은 18–22프레임이다.
실제 무기 궤적/공격 판정·몬스터 공격 규칙과 맞춰 조정해야 한다.
Jump는 약 8프레임부터 시각적으로 들리고 30프레임 부근에 돌아온다.
루트의 평면 이동은 없고 골반/몸통의 높이 변화만 있으므로 게임의 중력/점프 이동과 중복해서 높이를 적용하지 않는다.
Death는 반복하지 않고 마지막 프레임을 유지한다. Hit는 약 0.08초로 진입해 현재 이동 상태로 복귀하는 것을 제안한다.

## 환경 애니메이션

- Door_Hinged: Open/Close 1–36, 왼쪽 경첩 축 회전.
- Chest_Hinged: Open/Close 1–30, 뒤쪽 뚜껑 축 회전.
- Tree_Dead_A/B, Tree_Infected: Wind 1–90, 상부 흔들림.
- Grass_Dry_Clump/Reeds/Fungal: Wind 1–72, 잎/줄기 흔들림.
- Colony_Small/Large: Pulse 1–120, 작은 맥동.

환경 GLB의 실제 액션 이름에는 자산 접두사가 붙을 수 있다. 파일별 정확한 이름은 `asset_integrity.json`에 기록했다.
고정 건축물과 바위의 걷기/뛰기 애니메이션은 만들지 않는다.

## 재생 확인

`Previews/04_*_Motion.png`는 기준 자세·걷기·뛰기·회전·공격·점프의 실제 스킨 변형 중간 프레임이다.
연속 동작·부품 교체 후 겹침·다른 게임 엔진의 좌표 변환과 실제 블렌드 결과는 `.blend`/GLB 재생으로 확인한다.
별도 얼굴 표정 리그, 런타임 IK 시스템, 손가락별 그립 변경, 천 물리, 충돌체와 애니메이션 상태 머신 코드는 포함하지 않는다.
