# 모듈 조립 규격

## 인간형 Human_7H_v1

기준 신장 1.82m = 머리 단위 0.26m × 7. 맨몸 머리 꼭대기까지의 기준이며 후드·뿔·신발 장식은 별도다.
원점은 발 사이 지면, X는 좌우, -Y는 정면, Z는 위다. 좌우 이름은 캐릭터 자신의 시점이다.
모든 모듈은 완성 신체 안에서의 위치로 저장했으므로 같은 리그에서 위치·회전·스케일을 초기값으로 두고 겹치면 연결된다.

| 슬롯 | 선택 규칙 |
|---|---|
| head | Head_Ashen / Head_Pale / Head_Umber 중 하나 |
| face | Face_Quiet / Face_Weathered / Face_Umber 중 하나; 머리와 별도인 눈·코·입·흉터 세부 |
| hair | 짧은/긴 머리 중 선택; 후드·헬멧 내부 겹침이 보이면 해제 |
| headwear | 후드 또는 헬멧, 생략 가능 |
| torso | 맨몸/리넨/가죽/철 중 하나; 해당 슬롯의 맨몸을 옷 아래에 중복 표시하지 않음 |
| arms | 맨팔/리넨/가죽/철 중 하나; 양팔 한 모듈 |
| hands | 맨손 또는 장갑; 양손 한 모듈 |
| legs | 맨다리/리넨/가죽 중 하나; 양다리 한 모듈 |
| feet | 맨발/가죽 장화/철 장화 중 하나; 양발 한 모듈 |
| skirt | 순례자 겉옷/치유사 겉옷/경비병 타바드, 생략 가능 |
| cape | 순례자/치유사 망토, 생략 가능 |
| shoulders | 추가 철 어깨 장식; Arms_Iron에 이미 어깨가 있으므로 중복 선택 피함 |
| gear, back | 약병·주머니 또는 배낭. 망토와 배낭은 상황에 맞게 하나를 선택 |
| weapon | 검 또는 작업 망치; hand.R에 가중치 적용 |
| mutation | 뿔·딱지, 생략 가능 |

`human_presets.json`에 조합 예시를 기록했다. 기본 부품의 피부 재질은 AshSkin이며,
다른 피부색으로 새 조합을 만들면 목·맨팔·맨손·맨다리의 피부 재질도 동일하게 맞춘다.
모듈 자체를 비균일 스케일로 늘리면 봉합 위치와 리그가 어긋난다. 전체 크기는 공통 리그의 균일 스케일로 조절한다.

핵심 연결 높이는 발목 0.105m, 무릎 0.51m, 골반 약 0.95m, 어깨 1.44m, 머리 시작 1.56m다.
소켓은 `socket.hand.L/R`, `socket.back`, `socket.belt`, `socket.head`이며 비변형 본이다.
무기는 이미 손에 스키닝되어 있으므로 스킨과 본 소켓 부착을 동시에 적용해 변형을 두 번 하지 않는다.

Blender에서는 라이브러리의 같은 Armature를 유지하고, Outliner에서 기존 슬롯을 숨긴 뒤 대체 부품의 표시와 렌더를 켠다.
각 모듈 GLB에도 기준 골격이 들어 있다. 게임에서 조합할 때는 본 이름과 inverse-bind 행렬로 한 스켈레톤에 연결한다.
모듈마다 별도 스켈레톤을 계속 재생하는 방식은 제공 목적과 다르다. 조합 GLB는 처음부터 하나의 스킨/스켈레톤을 공유한다.

## 몬스터

| 계열 | 리그 | 기본 슬롯 | 추가 슬롯 |
|---|---|---|---|
| 동물형 사족 | Animal_v1 | 몸통·머리·사지·꼬리 | 가시/뿔 또는 군체 왕관 |
| 거미형 8족 | Spider_v1 | 몸통·머리·8개 다리 묶음 | 가시 껍질 또는 번식낭 |
| 거대 이족 | Giant_v1 | 몸통·머리·사지·천 조각 | 어깨 가시 또는 성자 왕관 |

같은 계열 안에서는 부품 원점·봉합 위치·본 이름을 공유한다. 계열 사이에는 리타기팅 또는 재스키닝이 필요하다.
현재 좌/우 다리는 하나의 사지 모듈로 묶었다. 다리 한 개씩 독립 교체하는 규격까지 구현한 것은 아니다.
약함·위험·보스는 그래픽 분류이며 전투 능력치나 AI를 설정하지 않는다.
각 조합의 크기와 부품 목록은 `asset_manifest.json`의 `root_scale`, `modules`에 있다.

## 건축과 자연

바닥은 2×2m, 벽은 폭 2m·높이 2.4m, 기둥은 지면 중심 피벗이다. 생활 도구는 지면 중심을 기준으로 제작했다.
벽의 문과 창에는 실제 빈 개구부가 있다. 문 모듈은 중앙 배치 기준 폭 약 0.88m이며 왼쪽 경첩 본으로 열린다.
문틀 모듈 중앙에 같은 위치로 배치하면 맞는다. 상자는 바닥 원점과 후면 뚜껑 경첩을 가진다.

지붕 패치는 X 폭 2m, Y 길이 2m, 처마 Z=0에서 용마루 Z=1.2m까지 올라간다.
4×4m 집은 두 패치를 X 방향으로 놓고 반대편 패치를 Z축 180도 회전해 맞춘다.
박공은 폭 2m 단위이므로 4m 폭 집에서는 로컬 X를 2배로 한다. 용마루는 길이 2m다.
계단은 높이 약 0.96m인 독립 모듈이다. 조립 예시에서는 낮은 현관에 맞게 Z 스케일 0.1875로 사용했다.
실제 적용 예시는 `Settlement_Assembly_Example.blend`의 변환을 따른다.

자연 지면 타일은 2×2m이고 가장자리 높이를 0으로 맞췄다. 서로 다른 재질의 경계 혼합/데칼 시스템은 포함하지 않는다.
나무·풀·군체는 자체 작은 리그와 Wind/Pulse 클립을 가지고, 바위·그루터기·알·균사 뿌리는 정적이다.
환경 라이브러리는 목록 확인을 위해 부품을 이동 배치했다. 재사용할 때 해당 오브젝트/Armature의 위치를 초기화하거나 원점 상태의 개별 GLB를 사용한다.

## 색과 재질

잿빛/창백한 피부, 차콜 천, 빛바랜 리넨, 마른 핏빛 천, 낡은 가죽, 녹슨 철, 변색 황동,
오래된 뼈, 죽은 목재, 그을린 석재, 석회 벽, 청회색 점판암, 묘토, 마른 풀, 오염토, 균사·변이 살·키틴을 사용했다.
원본 PNG는 반복형 제작 재질이며 특정 물체에 손으로 그린 고유 텍스처나 스캔 재질이 아니다.
Normal은 OpenGL 방식(+Y)이다. BaseColor는 sRGB, Roughness/Normal/Height는 Non-Color로 사용한다.
금속성은 `asset_manifest.json`의 재질별 상수를 따른다.
